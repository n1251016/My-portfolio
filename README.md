# Portfolio

## 概要
Webデザイナー・フロントエンドエンジニアを目指して制作したポートフォリオサイトです。
制作したWebサイトやバナーを掲載しています。

## 使用技術
- HTML
- CSS
- JavaScript

## 制作について
このポートフォリオサイトは、下記テンプレートをベースに制作しています。

https://webdesigner-go.com/template/portfolio-02/

テンプレートのコードを読みながら構成を理解し、自分のポートフォリオとしてレイアウトやデザイン、掲載内容を編集・調整しました。

制作を通して、HTML・CSS・JavaScriptの使い方だけでなく、既存のコードを読み解きながら修正・実装する力も身につけました。

## 工夫した点
- 制作物が主役になるよう、シンプルなデザインを意識しました。
- 閲覧する人が迷わず作品を見られるよう、レイアウトや導線を調整しました。
- テンプレートのコードを理解しながら、自分のポートフォリオに合わせてデザインや構成を編集しました。
